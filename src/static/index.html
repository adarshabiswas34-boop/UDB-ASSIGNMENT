Rate Limiting Algorithms

🪟
Sliding Window Log
Tracks exact request timestamps in Redis. Most accurate — no burst spikes at window edges.
🪣
Token Bucket
Tokens refill at a steady rate. Allows short bursts while enforcing a long-term average.
⏱️
Fixed Window
Resets the counter at fixed intervals. Lightweight and predictable for simple use cases.
